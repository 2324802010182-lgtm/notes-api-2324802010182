Phần B: Mô phỏng hạ tầng đám mây với CloudSim Plus 9.0.0

Kịch bản mô phỏng Lớp thực thi Kết quả & Nhận xét kỹ thuật
1. Cơ bản (Basic) BasicFirstExample 4 Cloudlet (10.000 MI) chạy song song trên 2 VM (4 core), hoàn tất đồng loạt tại 20.1s (ExecTime = 20.0s).
2. Lập lịch Cloudlet TimeSharedExample1 vs SpaceSharedExample1 TimeShared: chạy đồng thời chia sẻ CPU nên ExecTime tăng gấp đôi (20.0s).
SpaceShared: chạy tuần tự theo nhóm core nên ExecTime giữ nguyên 10.0s/tác vụ (hoàn tất tại 20.2s).
3. Định vị VM (BestFit) DynamicVmPlacementPolicyBestFitExample Gom VM 0 và VM 1 (2 core) lấp đầy Host 0 (4 core) trước khi đặt VM 2 sang Host 1 (5 core), tối ưu mật độ máy chủ vật lý.
4. Co giãn tự động LoadBalancerByHorizontalVmScalingExample Tự động sinh thêm VM mới khi tải tăng cao và phân phối đều các Cloudlet qua bộ cân bằng tải, hoàn tất mô phỏng tại 122.31s.
