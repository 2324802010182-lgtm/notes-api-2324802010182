2. Đối chiếu 5 Đặc tính Điện toán Đám mây theo NIST

  • 1. Tự phục vụ theo yêu cầu (On-demand Self-service):** Sinh viên tự bấm nút "Create codespace" trên GitHub để cấp phát máy ảo đám mây trong vài phút mà không cần quản trị viên can thiệp thủ công.
  • 2. Truy cập mạng rộng (Broad Network Access):** API Node.js sau khi chạy có thể truy cập linh hoạt từ bất kỳ thiết bị nào (máy tính, điện thoại di động) qua mạng Internet thông qua đường dẫn HTTPS công khai.
  • 3. Gộp tài nguyên (Resource Pooling):** Máy ảo Codespace chạy trên hạ tầng đám mây Azure của Microsoft, chia sẻ chung kho tài nguyên phần cứng (CPU/RAM) nhưng vẫn đảm bảo tính cô lập giữa các container.
  • 4. Co giãn nhanh (Rapid Elasticity):** Có thể dễ dàng thay đổi cấu hình máy ảo (tăng/giảm số core CPU, RAM) hoặc bật/tắt máy ảo tức thì theo nhu cầu sử dụng thực tế.
  • 5. Dịch vụ đo lường được (Measured Service):** Hệ thống tự động theo dõi và báo cáo chính xác mức độ tiêu thụ tài nguyên theo thời gian (hiển thị số core-hours và storage GB-tháng trong mục Billing Usage).
